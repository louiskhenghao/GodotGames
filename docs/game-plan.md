# Ring Rush — 游戏策划与制作方向

核心体验是：左手走位、自动出拳，右手在关键时机闪避或释放招式；每次击倒带来反馈，每五波出现一个值得期待的战斗节点。操作和菜单应服务这个循环。

## 本轮已经落地

| 玩家需求 | 游戏中的实现 |
| --- | --- |
| 更容易选拳手 | 左右滑动／箭头切换，实际 3D 展示、三项属性、招式和解锁按钮同屏 |
| 招式不用读长文 | 六种图形、六种颜色、简短用途说明，可直接试放技能 |
| 双手自然操作 | 左侧移动区；右侧圆形闪避、技能、终极技能，支持第二根手指 |
| 外观有区别 | 男女两套独立人体底模，加入重型护具、头盔、面罩、发型、护腕及腰带 |
| 场地更丰富 | 擂台、长街、八边形天台、横向工厂、六边形庭院；障碍物有碰撞和绕行 |
| 商业化体验 | 主菜单广告位；自愿复活与胜利奖励；永久去广告；奖励去重和恢复 |

目前有六个组装后的角色身份，仍只有两套人体原始雕模。下一轮美术应制作独立脸部、服装网格与更自然的格斗待机／连击动作，优先两名主角形成质量标准，再扩展整套阵容。

## 广告与公平性决策

- 战斗中不显示广告。菜单横幅让开主要操作；退出每第三局结算时可出现插屏。
- 同一局已经获得自愿广告奖励，跳过结算插屏。
- 每局只有一次广告复活，恢复 60% 生命并给 3 秒保护；失败后仍能保留本局金币。
- 胜利奖励先正常入账，玩家可自愿看广告再获得 50%。不看广告也能正常解锁全部金币角色和招式。
- 永久去广告移除横幅和自动插屏，保留玩家主动选择的奖励视频。
- 当前为明确标记的测试广告与测试购买，没有接入真实广告网络或扣款。正式广告的时长和关闭按钮由 SDK 管理，奖励只认完成回调。

## 下一阶段优先顺序

1. **让战斗更有变化。** 优先给五个 Boss 做不同攻击逻辑：冲锋撞墙、扇形连拳、召唤包围、追踪落点、两阶段反击。现在的 Boss 仍共享范围重击，单纯增加波数不能替代新战术。
2. **前一分钟教学。** 先通过走位躲一次红圈，再引导一次地震清场；第二波后才介绍终极技能。只展示当前需要的操作，并提供跳过／重看。
3. **建立美术和手感样板。** 优先精修 Atlas 与 Zephyr 的脸、服装、护拳姿势和重心变化；录制移动、出拳、受击、终结的对比片。模型预算以目标手机实测为准。
4. **给长期游玩明确目标。** 每日三个短挑战、角色专属熟练度和外观奖励；让 10 波局成为主要入口，30/50 波和阶梯作为耐力挑战。避免强制签到或用付费属性堵住进度。
5. **用数据调节难度。** 在得到玩家同意并完成隐私设计后，记录教学完成率、死亡波数、招式使用率、角色解锁时间及自愿广告选择率。先验证首局理解度和连续玩三局的体验，再调收益参数。
6. **完成真实移动发行。** 接入 Android/iOS 广告和商店适配器、正式恢复购买与收据验证；低端 Android 和较旧 iPhone 做持续游玩、发热、触控、后台恢复和广告中断测试。

当前自动测试可以证明解锁、碰撞、波数、存档和奖励逻辑正确；是否刺激、是否愿意继续玩，需要真实玩家试玩来判断。建议首轮让 5–8 位新玩家各玩三局，观察他们是否无需解释就能移动、选招、闪避和理解复活选项。

## 本轮游戏质量改进与下一步建议

已把场景选择重排为“上方真实地图、下方场景和模式”，把升级变成短动画弹窗；加入角色拖动旋转、稳定菜单背景、近景跟随镜头，以及受击／倒地／淡出和反馈声。弹窗保留战斗画面但暂停模拟，避免玩家选技能时被打。

下一阶段建议集中做三个可感知的战斗机制：

1. **精准闪避与反击。** 在攻击落下前的短窗口成功闪避，触发清晰的提示，并给一次短暂反击机会。先验证判定公平和反馈清楚，再加入连击奖励。
2. **不同 Boss 的战术。** 每五波的对手应要求不同走位：直线冲撞、扇形连拳、包围召唤、延迟地面追击。敌人变化比继续增加数值或波数更能减少重复感。
3. **可理解的技能组合。** 把三选一的升级整理成明确路线，例如火焰持续伤害、雷电群体连锁、近身闪避反击；选择时显示它对当前构筑的作用，减少暂停思考。

先让新玩家连续玩三局，观察能否看懂攻击预警、是否主动使用闪避，以及第二局是否愿意尝试另一角色。根据这些反馈调节节奏；不要把“想一直玩”当成自动测试可以证明的指标。

## 界面与战斗充实版本

已完成技能卡片自适应高度、蓝色升级弹窗、居中明亮通关提示；首页右侧 Fighter / Skills / Shop 图标导航，左侧 Gym，底部 Play。Gym 提供力量、生命、起手能量、移动速度、招式冷却五项金币成长，每项五级。商店提供 500 / 1500 / 4000 金币的免费测试购买，真实 IAP 尚未接入。

场地长宽扩大 30%（面积约 +69%），保留近景跟随镜头。敌人增加女性敏捷体型和重装体型；第四波起加入冲锋、锁定落点闪电、护甲重击，要求闪避直线、离开预警圈、用招式破甲。关闭额外粒子也不会隐藏关键招式反馈。

两个用户提供的 FBX 已完成导入、减面和动作适配试验。外观可用，但自动重定向的姿势未达标，尚未作为可购买拳手上线；详细结果在 `docs/model-review/README.md`。建议下一步先获得正确绑定姿势，完成一个新角色从移动到出拳、受击、倒地的完整样板，再批量扩展角色。
