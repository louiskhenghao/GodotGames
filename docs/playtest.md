# Ring Rush 0.4.0 — 朋友试玩版

## Mac（最方便直接发朋友）

把 `RingRush.zip` 发给朋友。解压后打开 **Ring Rush.app**，无需安装 Godot。支持 Apple Silicon 和 Intel Mac。

应用使用本地 ad-hoc 签名，未经过 Apple notarization。若下载后被 macOS 拦截，可在「系统设置 → 隐私与安全性」中针对 Ring Rush 选择「仍要打开」。不需要关闭系统整体安全保护。

## 网页

把 `RingRush-Web-Playtest.zip` 整包上传至支持静态 HTML 游戏的平台（例如 itch.io 的 HTML game），解压后的根目录必须有 `index.html`。也可以放在自己的 HTTPS 静态网站。当前交付的是文件包，尚未发布公开网址。

本机预览：在解压目录运行 `python3 -m http.server 8769`，然后浏览器打开 `http://localhost:8769`。不要直接双击 HTML 文件。浏览器需要 WebGL 2 和 WebAssembly；首次下载约 122 MB，实际速度取决于服务器和网络。

建议手机竖屏。桌面浏览器会居中显示竖屏游戏。点一下游戏后浏览器才会允许播放声音。

## 怎么玩

- 左下拖动行走；电脑也可 WASD / 方向键移动。
- 靠近敌人自动出拳，闪开红色攻击预警。
- 右侧圆形按钮使用技能；键盘 Q 是技能、Space 是闪避、E 是满能量大招。
- Esc 暂停。升级时点击一张技能卡，继续战斗。
- GYM 点击金币按钮升级永久属性，再点击底部 PLAY，选择场地/模式后 FIGHT 开战。

试玩首次送 **1,200 金币**。6 位人类拳手、3 位机器人拳手、6 种主动招式、18 种被动升级、5 个常规场地、1 个隐藏场地和 9 个模式可体验。新手先玩 Quick Fight；想体验紧凑节奏可选 Blitz、Hell 或 Boss Rush。

首页 PLAY 统一进入场地和模式选择；点击 FIGHT 直接开战。四个彩色入口依次为 Fighter、Skills、GYM、Shop。选择不同拳手会看到不同背景。技能页面的 TRY EFFECT 会进入面朝镜头的擂台演示。

骷髅只出现在隐藏模式：在模式页选择 SEALED ENCOUNTER，再用 600 金币 UNLOCK RIFT。只付一次；普通模式没有骷髅。旧版买过骷髅拳手会退还金币并保留招式，旧战斗会迁移为人类角色。

角色/技能用游戏金币解锁。商店标明 TEST 的购买是免费模拟，广告也是模拟；本版本不会扣真钱。若金币不足，可在 Shop 点击 TEST FREE 补充。Remove Ads 保留自愿奖励视频。

试玩存档独立于开发和正式存档。浏览器存档绑定当前网站地址与浏览器；清理网站数据或使用无痕窗口会影响保留。暂停、切出游戏和过波时保存，进行中的战斗也定期保存。意外退出可能丢失最近一小段进度。

## 新成长系统

- AEGIS / ION / ONYX：三套新机器人模型，1,800 / 2,600 / 3,600 金币解锁，能力各有侧重。
- GYM：8 个项目，每项 30 级；Bronze 到 Master 六种段位。新增减伤、过波恢复、金币加成。
- Skills：每招可升到 10 级，增加伤害和范围；5 / 10 级出现更丰富的特效。TRY EFFECT 的左上返回也会回到 Skills。
- Badges：主页右上皇冠或 GYM 底部进入，共 36 个；达成后自动获得小幅永久属性，无需逐个领取。
- GYM 下方可选 Hard Contract：敌人更强，战斗金币 +25%。普通成长也会适度增强敌人，但成长收益仍明显。
- 旧存档、角色、金币和原有训练保留；进行中的战斗沿用开始时的成长数值。

## 最有用的反馈

试玩 5–10 分钟，记录所用设备/浏览器、模式、角色和波数。告诉我：什么时候觉得爽，什么时候觉得拖沓；什么攻击来不及看清；哪一个按钮第一次没看懂。遇到问题时附上复现步骤或短录像即可。

## 本轮内容与边界

- 连续全高背景、居中图标、统一技能弹窗、独立 Fight 底部动作区。
- Shop / GYM 改为双列图形卡牌，GYM 开始按钮始终可见。
- Rattle、Shade、Hex 三个 CC0 骷髅模型仅作隐藏场地的敌人。
- 新增 Hell 20 波、Blitz 8 波、Boss Rush 5 战；保留 30 / 50 波和阶梯模式。
- 每个模式都有不同旋律、鼓点和音色的原创编曲，不是变速版本。

Web 和 Mac 已做实际启动及浏览器操作测试。Android/iOS 的共用项目、触控和导出配置保留；手机安装包签名、真机性能、真实广告及商店支付仍待集成和验证。
